# Can Ozan Gürleyen — Portfolio

Hi — I'm Can (Ozan) Gürleyen, a Game Design student at the University of Liverpool. This repository contains a lightweight portfolio site that showcases prototypes, web projects and experiments.

## About

I build interactive experiences and prototypes using both game engines and web technologies. My work focuses on rapid prototyping, gameplay systems and tools. I use:

- C# (Unity)
- JavaScript / TypeScript (web & React)
- HTML & CSS
- Python
- PostgreSQL
- Embedded systems / Arduino

This portfolio demonstrates a mix of web and game-focused projects, with tag filtering and expandable project previews.

## Projects

Browse the `index.html` page (this repository's GitHub Pages index) to see project cards. Each card includes short and long descriptions, tags and a placeholder screenshot. Use the tag filters on top to quickly find projects by technology.
